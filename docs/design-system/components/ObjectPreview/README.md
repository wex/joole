A preview of the selected object's texture at the top of the properties panel.

**The consumer provides:** the selection's texture bitmap and name, or the fact that the selection has several textures.

- The preview is a square on `vp-bg`. A single texture is shown pixelated, with its name on a `select` label.
- If the selection has several textures, show "Multiple textures" in `vp-label` (Qoole: "Multiple Textures").
- With nothing selected, hide the preview rather than showing an empty black square.
